# Phase 7 Privacy Records Completion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Finish Phase 7 by generating the personal-data inventory and Article 30 processing record from the privacy registry and failing CI when either document drifts.

**Architecture:** `shared/procuresignal/privacy/inventory.py` remains the only source of privacy-table facts. A deterministic Python renderer exposes pure functions for tests and a CLI that either writes both documents or checks committed bytes without changing the working tree.

**Tech Stack:** Python 3.11, dataclasses, argparse, pytest, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-10-production-completion-design.md`

## Global Constraints

- The registry is the single source of truth; neither generated document maintains a second table list.
- Generated bytes are independent of current time, locale, machine, and absolute checkout path.
- Legal conclusions that code cannot establish are emitted as `OWNER INPUT REQUIRED`, never guessed.
- `--check` is read-only and returns non-zero while naming every stale document.
- Existing export, erasure, retention, and audit behavior is unchanged.
- Every production change follows red-green-refactor and the complete backend gate runs before push.

## Review Focus

- A registry entry containing Markdown metacharacters must render as data without corrupting the table.
- Duplicate or unregistered table names must fail generation instead of producing an authoritative-looking incomplete record.
- `retention_days=None` must render as an explicit policy state, not as zero days or an empty cell.
- `--check` must report both stale documents in one run so one fix does not hide the second drift.
- Running the writer twice with no registry change must leave identical bytes.

- [ ] **Step 3: Implement pure rendering and CLI behavior**

Create `scripts/generate_privacy_docs.py` with this public shape:

```python
from __future__ import annotations

import argparse
from collections.abc import Mapping, Sequence
from pathlib import Path

from procuresignal.privacy.inventory import INVENTORY, PersonalDataTable, unregistered_tables

ROOT = Path(__file__).resolve().parents[1]
INVENTORY_PATH = ROOT / "docs" / "personal-data-inventory.md"
RECORD_PATH = ROOT / "docs" / "processing-record.md"


def _cell(value: object) -> str:
    return " ".join(str(value).split()).replace("|", r"\|")


def _retention(entry: PersonalDataTable) -> str:
    return f"{entry.retention_days} days" if entry.retention_days is not None else "No automatic expiry"


def render_personal_data_inventory(entries: Sequence[PersonalDataTable]) -> str:
    lines = [
        "# Personal data inventory",
        "",
        "<!-- Generated by scripts/generate_privacy_docs.py; do not edit. -->",
        "",
        "| Table | Subject link | Purpose | Erasure | Retention | Note |",
        "|---|---|---|---|---|---|",
    ]
    for entry in sorted(entries, key=lambda item: item.table):
        link = (
            "None"
            if entry.link_column is None
            else f"{entry.link.value}: `{entry.link_column}`"
        )
        lines.append(
            "| "
            + " | ".join(
                (
                    f"`{entry.table}`",
                    _cell(link),
                    _cell(entry.purpose),
                    _cell(entry.erasure.value),
                    _cell(_retention(entry)),
                    _cell(entry.retention_note or "None"),
                )
            )
            + " |"
        )
    return "\n".join(lines) + "\n"


def render_processing_record(entries: Sequence[PersonalDataTable]) -> str:
    lines = [
        "# GDPR Article 30 processing record",
        "",
        "<!-- Generated by scripts/generate_privacy_docs.py; do not edit. -->",
        "",
        "## Controller and legal review",
        "",
        "- Controller identity: **OWNER INPUT REQUIRED**",
        "- Lawful-basis approval: **OWNER INPUT REQUIRED**",
        "- International transfers: **OWNER INPUT REQUIRED**",
        "- Audit retention under Article 17(3)(b) and (e): **OWNER INPUT REQUIRED**",
        "",
        "## Technical and organisational measures",
        "",
        "Tenant isolation, role-based access, append-only audit records, token revocation, "
        "bounded retention, subject export and controlled erasure are enforced in code.",
        "",
        "## Processing activities",
        "",
        "| Table | Purpose | Data-subject link | Erasure | Retention |",
        "|---|---|---|---|---|",
    ]
    for entry in sorted(entries, key=lambda item: item.table):
        lines.append(
            "| "
            + " | ".join(
                (
                    f"`{entry.table}`",
                    _cell(entry.purpose),
                    _cell(entry.link.value),
                    _cell(entry.erasure.value),
                    _cell(_retention(entry)),
                )
            )
            + " |"
        )
    return "\n".join(lines) + "\n"


def generated_documents(
    entries: Sequence[PersonalDataTable] = INVENTORY,
) -> dict[Path, str]:
    if unregistered_tables():
        raise RuntimeError(f"unregistered tables: {sorted(unregistered_tables())}")
    names = [entry.table for entry in entries]
    if len(names) != len(set(names)):
        raise RuntimeError("privacy inventory contains duplicate table names")
    return {
        INVENTORY_PATH: render_personal_data_inventory(entries),
        RECORD_PATH: render_processing_record(entries),
    }


def check_documents(documents: Mapping[Path, str]) -> list[Path]:
    return sorted(
        path for path, expected in documents.items()
        if not path.exists() or path.read_text() != expected
    )


def main() -> int:
    parser = argparse.ArgumentParser()
    parser.add_argument("--check", action="store_true")
    args = parser.parse_args()
    documents = generated_documents()
    if args.check:
        stale = check_documents(documents)
        for path in stale:
            print(f"stale generated document: {path.relative_to(ROOT)}")
        return 1 if stale else 0
    for path, content in documents.items():
        path.write_text(content)
    return 0
```

Route the stale-document messages to stderr in committed code, add the ordinary `if __name__ == "__main__"` exit wrapper, and keep the renderer bytes exactly as exercised above.
